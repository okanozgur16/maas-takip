# Maaş Takip

Haftalık vardiya ve maaş takibi. **Hesap, e-posta ya da yapay zeka gerekmez.**

- Veriler (vardiyalar, bordro tutarları, ayarlar) sadece kullanıcının kendi telefonunda/tarayıcısında saklanır; hiçbir sunucuya gönderilmez.
- Bordro PDF'i telefonda okunur. Ad, adres, BSN, IBAN kaydedilmez.
- Sayfa açıldığında hiçbir dış siteye bağlanmaz. Bir kez açıldıktan sonra internetsiz de çalışır.
- Telefon değişirse: Ayarlar › Yedek › "Yedeği indir" / "Dosyadan geri yükle".

Kullanmak için: https://okanozgur16.github.io/maas-takip/
